# CPU
Bộ xử lý trung tâm. Thực thi các chỉ thị máy và thực hiện các phép toán, điều khiển hoạt động xử lý.

# RAM
Bộ nhớ chính, lưu dữ liệu và mã lệnh đang được hệ thống sử dụng.

# Storage
Lưu dữ liệu lâu dài, chẳng hạn hệ điều hành, chương trình và tài liệu.

# Operating System
Hệ điều hành quản lý tài nguyên và cung cấp môi trường cho chương trình hoạt động.
